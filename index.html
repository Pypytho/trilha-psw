Módulo 01: CSS3 Moderno

Construindo layouts responsivos com alinhamentos bidimensionais e unidimensionais.

Flexbox

Unidimensional. Perfeito para alinhar itens em linha ou coluna, distribuindo espaços dinamicamente.

CSS Grid

Bidimensional. Projetado para gerenciar linhas e colunas ao mesmo tempo, criando o layout macro do site.

Box Model

Define como margens, bordas, preenchimentos (padding) e o conteúdo interagem na renderização.
